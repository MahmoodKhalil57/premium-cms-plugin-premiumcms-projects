# @premium-cms/plugin-premiumcms-projects

The PremiumCMS control-plane plugin. Trusted and in-process: every instance
ships it inside the `instance` golden bundle (inert until Cloudflare
credentials are configured), which is what makes any instance a platform.

Provisioning, the recursive roll, themes-as-repos, plugins-as-repos, platform
and custom domains, credits. Published to npm on push; bump `version` to release.
